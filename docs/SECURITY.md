# 安全规则

## 凭据与版本控制

- `.env` 和 `.env.*` 不提交 Git；仅允许无真实值的 `.env.example`。
- 不输出、记录或提交 API Key、App Secret、Token、私钥或完整身份标识。
- `backups/` 和 `storage/` 中的运行数据不进入 Git，只允许 `.gitkeep` 占位。
- 数据库 dump、日志和缓存不进入 Git。

## 网络与入口

- PostgreSQL 5432 不对公网开放。
- API 当前只绑定 `127.0.0.1:8000`。
- 飞书入口只接受已授权的 tenant、sender 和 chat type，默认仅允许 `p2p`。
- 健康、生活、求职等敏感数据不得在群聊或确认回复中回显全文。

## 数据与变更安全

- 数据库备份必须非空并生成 SHA-256 校验值。
- 破坏性迁移前必须完成备份和恢复验证。
- 未经用户批准不得执行 downgrade、删除数据、删除 Docker volume 或其他破坏性操作。
- 不使用未经审批的危险 Codex/代理执行模式或绕过沙箱、权限和确认流程。
- 用户隐私不得写入日志；拒绝日志使用脱敏标识和机器可读原因。
- 健康和生活数据默认视为敏感数据，求职等个人记录同样遵循最小披露。
- 私钥不得共享；Token 不得提交；所有日志在展示或导出前必须脱敏。
- API、Worker 和后台任务均执行相同的用户隔离与授权规则。

## AI 代理规则

AI 代理必须以最小权限工作，先只读验证目标和影响面。任何删除、覆盖、生产迁移、外部发布或凭据相关操作都必须获得明确批准。
