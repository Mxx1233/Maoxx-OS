# Maoxx OS 项目说明

## 定位

Maoxx OS 是一个主要通过飞书聊天使用的个人 AI 操作系统。系统当前服务于单用户 Maoxx，但数据库、权限边界和代码结构必须保留未来多用户扩展能力。

飞书是日常交互主入口，目标交互形态包括文字、图片、文件和交互卡片。服务器终端仍用于部署、迁移、备份、恢复和故障处理。

## 技术栈

- Ubuntu 24.04
- Docker Compose
- PostgreSQL 16
- FastAPI
- SQLAlchemy
- Alembic
- 飞书 WebSocket Worker

服务器是后台运行和维护环境；飞书是用户的主要日常界面。当前采用单用户模式，但核心数据、API 身份上下文和权限设计保持 multi-user ready。

文件在前期保存在服务器本地存储中，使用与存储后端无关的键定位；后期可打包迁移到腾讯云 COS。知识库、向量检索、RAG 和 Zotero 属于后续扩展，不应提前侵入当前阶段。

模型调用后续统一经过 Model Gateway。第一版只接入一个 OpenAI-compatible 模型，待出现明确需求后再扩展 provider 和路由；业务服务不直接绑定某个模型供应商。

## 主要模块

1. 项目管理
2. 论文项目扩展
3. 求职管理
4. 学习管理
5. 生活记录
6. 运动记录
7. 健康记录
8. 公共任务和提醒
9. 分析和报告
10. 后续知识库

## 核心产品原则

- PostgreSQL 是事实数据源，AI 不是最终数据源。
- 原始输入、AI 提取、人工确认和正式业务记录分层保存。
- 用户数据默认私密，输出、日志和飞书回复遵循最小披露原则。
- 按路线图逐阶段交付并验收，不跨阶段开发。
- 以持续运行十年以上为目标，保证数据可导出、迁移、备份、恢复和追溯。

## 当前非目标

- 暂不开发复杂 Web 前端。
- 暂不引入 Redis。
- 暂不采用 Kubernetes。
- 暂不拆分微服务。
- 暂不建设知识库、向量检索或 RAG。
- 暂不同时接入多个模型。
- 暂不开发多用户 UI。
