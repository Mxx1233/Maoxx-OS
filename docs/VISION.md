# Maoxx OS Vision

Maoxx OS 的最终目标，是成为真正属于用户自己的 Personal AI Operating System。

它不是聊天机器人，不是简单知识库，也不是简单待办工具。它以用户拥有的数据为基础，统一管理：

- Projects
- Thesis
- Career
- Study
- Life
- Workout
- Health
- Tasks
- Analytics
- Knowledge

AI 是助手，不是数据所有者，也不是事实数据源。AI 负责理解、提取、分类、建议和分析；重要业务记录在正式入库前必须支持确认与修正，且来源始终可追溯。

## 十年以上的设计目标

Maoxx OS 以持续运行十年以上为设计尺度，优先考虑稳定性、可维护性、可迁移性、数据安全和渐进演进。系统不依赖某一次聊天记录；重要背景、决策、规则、状态和运维知识必须保存在仓库中。

用户数据必须：

- 可导出
- 可迁移
- 可备份
- 可恢复
- 可追溯
- 不绑定单一模型供应商
- 不绑定单一云存储供应商

技术选择必须服务于数据主权和长期可维护性，而不是短期演示效果。
